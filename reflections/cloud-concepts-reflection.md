 I didn't realize how dependent I am on cloud technology, Until I started attending on our Cloud Computing (CCM101) subject. 
 I learned that a lot of software I use is powered by cloud-based technologies, 
 it became apparent to me that I am drawing on the benefits of cloud computing on a daily basis.

 One of the most used cloud solutions for me is Google Drive, which falls under the category of SaaS
 because it allows me to save files so that I can perform file sharing activities without dealing with any server or software. 
 Moreover, since it is available for anyone with a Google account, it belongs to the Public Cloud. 
 Another example of SaaS available on the Public Cloud is Facebook Messenger, which I use quite often. 
 While Meta manages all technology behind the service, it allows for communication with my friends, relatives, and schoolmates.
 Another frequently used service is Canva.

 Version control plays a vital role when it comes to developing cloud projects, another crucial life lesson I've learned.
 Cloud infrastructure usually involves many scripts, configuration files, and documentation, 
 which most probably are modified concurrently by more than one person. Thus, it can be simple to make conflicting 
 file versions and lose changes unless there's a version control system.
 Git and GitHub provide an easy way to monitor all changes made, work with teammates, and look at prior versions 
 of the work by using commits, branches, and pull requests. 
 These resources can prevent mistakes, enhance cooperation among individuals, and ensure the efficient, effective, 
 and secure operation of cloud resources. As a BSIT student, I believe that learning how to use the GitHub tool will 
 be advantageous for my professional career and my participation in cloud computing projects.
