# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of services for computing, storage, databases, networking, security, analytics, artificial intelligence, and other technology needs. AWS allows organizations to access cloud resources on demand and scale their infrastructure according to their requirements.

## Global Infrastructure

AWS operates a large global infrastructure made up of geographic Regions and Availability Zones. As of 2026, AWS has 39 launched geographic Regions and 123 Availability Zones. Each AWS Region contains multiple physically separated Availability Zones that are connected through high-bandwidth, low-latency networking. This architecture helps organizations build applications that are highly available, scalable, and fault tolerant.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS cloud services. Through the console, users can create and configure resources, select AWS Regions, monitor services, manage users, review usage, and monitor billing. The console provides access to more than 200 AWS services and tools.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides virtual servers that can be used to run applications in the AWS cloud. Users can select different instance types and configure computing resources according to their workload requirements.

### 2. Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service used to store and retrieve large amounts of data. It can be used for backups, application data, archives, media files, and other types of digital content.

### 3. Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows users to create a logically isolated network within AWS. It provides control over networking components such as IP addresses, subnets, routing, and security.

### 4. AWS IAM

AWS Identity and Access Management (IAM) allows organizations to control access to AWS resources. Administrators can manage users, roles, permissions, and policies to help ensure that resources are accessed only by authorized identities.

## Three Advantages

### 1. Extensive Global Infrastructure

AWS has a large worldwide infrastructure with many Regions and Availability Zones. This allows organizations to deploy applications closer to their users and design systems for high availability.

### 2. Broad Range of Services

AWS provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas. Organizations can therefore build and operate many types of applications using services from the same cloud platform.

### 3. Scalability and Flexibility

AWS allows organizations to provision cloud resources according to their workload requirements. Resources can be increased or decreased as demand changes, making AWS suitable for applications that experience changing levels of traffic.

## Typical Enterprise Use Cases

AWS can be used by enterprises for a variety of workloads, including:

* Hosting websites and enterprise applications
* Data storage, backup, and archiving
* Database management
* Application development and testing
* Disaster recovery and business continuity
* Data analytics
* Artificial intelligence and machine learning
* Global application deployment
* Migration of traditional IT infrastructure to the cloud
