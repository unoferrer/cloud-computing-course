# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a cloud computing platform provided by Google. It offers services for computing, storage, networking, databases, data analytics, artificial intelligence, machine learning, security, and application development. Google Cloud allows organizations to deploy and scale applications using Google's global infrastructure.

## Global Infrastructure

Google Cloud operates a global infrastructure made up of regions and zones. As of 2026, Google Cloud lists 43 regions and 130 zones across its global infrastructure. Regions are independent geographic areas that contain multiple zones, while zones serve as deployment areas within regions. Organizations can distribute resources across multiple zones and regions to improve availability, reliability, and protection against infrastructure failures.

Google Cloud also operates a global network connecting its infrastructure across many countries and territories. This infrastructure supports applications that require low latency, high availability, and global scalability.

## Cloud Management Console

The Google Cloud Console is a web-based management interface used to create, manage, monitor, and configure Google Cloud resources. Users can manage virtual machines, storage, networking, databases, security, and other services through the console. The console also provides tools for managing projects, permissions, billing, and cloud resources from a centralized interface.

## Four Core Services

### 1. Compute Engine

Google Compute Engine is an Infrastructure as a Service (IaaS) offering that allows users to create and run virtual machines on Google's infrastructure. It supports both Linux and Windows workloads and can be configured for different computing requirements.

### 2. Cloud Storage

Google Cloud Storage is a managed object storage service used to store unstructured data. Data is stored as objects inside buckets, making the service useful for backups, archives, application data, media files, and other large datasets.

### 3. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking functionality for cloud resources such as Compute Engine virtual machines and Google Kubernetes Engine workloads. VPC networks can be configured with subnets, network policies, routing, and other networking features.

### 4. Identity and Access Management (IAM)

Google Cloud IAM is an identity and access management system that controls who can access Google Cloud resources and what actions they are allowed to perform. IAM uses principals, roles, and resources to provide fine-grained access control and supports the principle of least privilege.

## Three Advantages

### 1. Strong Artificial Intelligence and Machine Learning Capabilities

Google Cloud provides infrastructure and services designed to support artificial intelligence and machine learning workloads. Its infrastructure includes specialized AI resources and accelerators that can support demanding AI and ML applications.

### 2. Global Network and Infrastructure

Google Cloud operates a global infrastructure with regions and zones distributed across the world. Its global network helps organizations deploy applications closer to their users and build highly available systems across multiple locations.

### 3. Strong Data and Analytics Capabilities

Google Cloud provides a broad collection of services for storing, processing, and analyzing data. These capabilities make the platform suitable for organizations that work with large datasets, business intelligence, analytics, and machine learning.

## Typical Enterprise Use Cases

Google Cloud can be used by enterprises for a variety of workloads, including:

* Hosting websites and enterprise applications
* Running virtual machines and application servers
* Data storage, backup, and archiving
* Big data processing and analytics
* Artificial intelligence and machine learning
* Kubernetes and containerized application deployment
* Application development and testing
* Global application deployment
* Disaster recovery
* Modernizing traditional IT infrastructure
