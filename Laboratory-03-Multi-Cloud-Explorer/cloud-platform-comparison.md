## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services among the three major providers. Its services cover computing, storage, databases, networking, security, analytics, artificial intelligence, and many other technology areas, making it suitable for organizations with diverse cloud requirements.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies such as Windows Server, Microsoft 365, SQL Server, and Microsoft Entra ID. This makes Azure a particularly suitable choice for organizations that already depend heavily on Microsoft's technology ecosystem.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in artificial intelligence, machine learning, data analytics, and Kubernetes. Google developed Kubernetes, and Google Cloud provides Google Kubernetes Engine (GKE), while also offering infrastructure and services designed for AI and ML workloads.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud Platform because of its strong capabilities in artificial intelligence, machine learning, data analytics, and Kubernetes. These technologies are increasingly important in modern cloud computing and application development. However, the best provider ultimately depends on the organization's technical requirements, existing infrastructure, budget, and business goals.

## Summary

AWS, Azure, and Google Cloud provide comparable core services for computing, storage, networking, identity management, databases, and Kubernetes. Although their services perform similar functions, each provider has different strengths and is designed to meet different organizational requirements.

The equivalent services demonstrate that organizations can often find similar cloud capabilities across providers. For example, Amazon EC2, Azure Virtual Machines, and Compute Engine all provide virtual machine infrastructure, while Amazon S3, Azure Blob Storage, and Cloud Storage provide object storage capabilities.
