# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft that provides services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development. Azure supports both cloud-native applications and organizations that want to migrate or extend their existing on-premises infrastructure to the cloud.

## Global Infrastructure

Azure has a large global infrastructure consisting of regions, geographies, datacenters, and Availability Zones. Microsoft currently lists more than 70 announced Azure regions and provides regional options designed to support data residency, compliance, performance, and resiliency requirements. Azure Availability Zones are physically and logically separated datacenters within an Azure region, with independent power, networking, and cooling. These zones help organizations design applications that remain available even when infrastructure problems affect an individual datacenter.

## Cloud Management Console

The Azure Portal is a web-based, unified management console used to create, manage, and monitor Azure resources. Users can manage virtual machines, databases, applications, networking resources, subscriptions, and costs through a graphical interface. The portal also provides global search, dashboards, Cloud Shell, notifications, settings, and other management tools.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provides scalable virtual servers that can run both Windows and Linux operating systems. Organizations can use Azure VMs to host applications, databases, enterprise software, and high-performance computing workloads.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data. It can be used for application data, backups, archives, data lakes, media files, and machine learning workloads.

### 3. Azure Virtual Network

Azure Virtual Network provides private networking capabilities for Azure resources. It allows organizations to create isolated networks, configure subnets and IP addresses, control network traffic, and connect cloud resources to on-premises infrastructure.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's identity and access management service. It helps organizations manage users, groups, applications, and access to cloud and on-premises resources. It also supports authentication and single sign-on for services such as Azure and Microsoft 365.

## Three Advantages

### 1. Strong Microsoft Integration

Azure integrates closely with Microsoft technologies such as Windows Server, Microsoft 365, SQL Server, and Microsoft Entra ID. This makes Azure particularly suitable for organizations that already depend heavily on Microsoft's technology ecosystem.

### 2. Global Infrastructure and Availability

Azure provides a large global infrastructure with regions and Availability Zones designed to support high availability, resiliency, performance, and data residency requirements. Organizations can deploy workloads in locations appropriate for their users and regulatory requirements.

### 3. Hybrid Cloud Capabilities

Azure supports hybrid environments that connect on-premises infrastructure with cloud resources. Services such as Azure Virtual Network and Microsoft identity solutions allow organizations to extend existing infrastructure into Azure while maintaining connections to their existing systems.

## Typical Enterprise Use Cases

Microsoft Azure can be used by enterprises for a variety of workloads, including:

* Hosting Windows and Linux applications
* Migrating Windows Server infrastructure
* Running enterprise databases
* Cloud backup and disaster recovery
* Hybrid cloud deployments
* Hosting web and mobile applications
* Data analytics and artificial intelligence
* Virtual desktop infrastructure
* Enterprise identity and access management
* Modernizing existing Microsoft applications
